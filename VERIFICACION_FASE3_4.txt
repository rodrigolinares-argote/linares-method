LINARES METHOD — FASE 3.4: COMPROBANTE POR WHATSAPP

OBJETIVO
Cerrar el flujo de pagos del Portal sin backend ni confirmaciones automáticas falsas.

IMPLEMENTADO
- Título actualizado a "Pago del abono".
- Aviso explícito al alumno:
  · tiene que enviar el comprobante por WhatsApp;
  · debe adjuntar la foto o archivo del comprobante antes de enviar el mensaje.
- Botón "Enviar comprobante por WhatsApp".
- Mensaje automático:
  "Hola Rodrigo, ya realicé el pago del abono del mes. Adjunto el comprobante de pago para que puedas verificarlo y registrarlo."
- Se utiliza el WhatsApp configurado en Perfil Profesional.
- Si no hay WhatsApp configurado, se muestra un aviso y no se abre un destino incorrecto.
- Las funciones viajan también al Portal HTML exportado.

REGLAS PROTEGIDAS
- Enviar comprobante NO marca el pago como Pagado.
- El entrenador verifica el comprobante y registra el pago.
- Pagar NO modifica fechaVencimientoServicio.
- El vencimiento sólo cambia mediante una renovación explícita.

NO SE MODIFICÓ
- Alumnos
- Rutinas
- Alimentación
- Suplementación
- Evolución
- Renovaciones
- PDF
- Backup
- IndexedDB
- Persistencia base
- PWA/iconos
